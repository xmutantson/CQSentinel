# CQSentinel Icon

Place `icon.ico` in this directory for Windows builds.

## Creating an Icon

You can create an icon from a PNG using:

### Online Tools
- https://convertico.com/
- https://cloudconvert.com/png-to-ico

### Command Line (ImageMagick)
```bash
convert icon.png -define icon:auto-resize=256,128,64,48,32,16 icon.ico
```

### Requirements
- Format: .ico
- Sizes: 16x16, 32x32, 48x48, 256x256 (multi-resolution)
- Transparency: Supported

## Temporary Icon

Until a custom icon is created, PyInstaller will use the default Python icon.

The application will still build and run correctly without a custom icon.
