# Research & Analysis Documents

This folder contains technical research, debugging analysis, and design exploration documents created during CQSentinel development.

## Contents

- **AUTO_CENTERING_ANALYSIS.md** - Design analysis for SSB/FM auto-centering algorithms
- **CONFIG_GAPS_ANALYSIS.md** - Configuration system gaps and improvements analysis
- **CRASH_ANALYSIS.md** - Investigation into Windows threading crashes with faster-whisper
- **FD_REDIRECTION_EVALUATION.md** - Field Day stdout/stderr redirection evaluation
- **WHISPER_THREADING_RESEARCH.md** - Research on Whisper model threading issues on Windows

## Purpose

These documents capture:
- Technical investigations
- Design decisions and trade-offs
- Debugging insights
- Performance analysis
- Architecture explorations

## For Developers

These documents are useful for:
- Understanding **why** certain design decisions were made
- Learning from debugging challenges encountered
- Avoiding known pitfalls with libraries (PyTorch, whisper, etc.)
- Reference when troubleshooting similar issues
